# Teams Web会議マニュアル

ベステラ社員向け、Microsoft Teams Web会議の使い方マニュアル。

公開ページ: https://hhasebe-besterra.github.io/teams-manual/

## 更新の流れ

1. `index.html` を編集
2. `git commit -am "..."` → `git push`
3. GitHub Pages が自動でデプロイ（数分以内に反映）
4. 重要な変更時のみ Teams で全社員に通知

- `index.html` — 本体ページ
- `README.md` — このファイル
